ドキュメントサイトのURLを入れると、本文を集めて
しおり・通しページ番号つきの1冊のPDFにまとめるデスクトップアプリ。

実験段階 / 未検証 — コードは一通り実装済みですが、実機でのビルドと実サイトでの動作確認はこれからです。配布ファイルはまだありません。

仕組み

  1. ページを見つけるllms-full.txt → llms.txt → sitemap.xml → ナビのクロール、の順に試します。sitemap はサイドバー順に並べ直します。
  2. 本文だけ取り出すReadability と、ドキュメントサイト向けのノイズ除去（目次・前後ナビ・フッターなど）を使います。
  3. 1本に連結する見出しの階層を整え、内部リンクを文書内ジャンプに、外部リンクはURL併記にします。
  4. PDFにする手元の Chrome / Edge を操作して、しおり付きのPDFを書き出します。

なぜデスクトップアプリか

  • ブラウザだけでは、他サイトのHTMLを取得できません（CORS）。取得は Rust 側で行います。
  • しおり付きPDFは、ブラウザ内の印刷では作れません。そのためローカルのブラウザをCDPで操作しています。

動作環境

  • Windows / macOS / Linux（Tauri v2）
  • Chrome または Edge がインストールされていること
